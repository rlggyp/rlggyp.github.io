# rlggyp.github.io

## Installation

To set up the project on your local machine, follow these steps:

1. **Clone the repository**:

   ```bash
   git clone https://github.com/rlggyp/rlggyp.github.io.git
   cd rlggyp.github.io
   ```

2. **Install Node.js**:

   Make sure you have [Node.js](https://nodejs.org/) installed. Check your installation with:

   ```bash
   node -v
   npm -v
   ```

3. **Install dependencies**:

   Run the following command to install all necessary packages:

   ```bash
   npm install
   ```

## Usage

To start the web portfolio, run:

```bash
npm run start
```
